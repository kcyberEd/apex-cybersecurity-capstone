# APEX Tech Forge Academy: Cybersecurity Capstone

In this capstone, I act as a Junior Security Analyst for APEX Tech Forge Academy, which has detected rising phishing attempts and unauthorised network scanning. I assess the threats, secure a Linux server, verify data integrity, and monitor network traffic.

## Phases
| Phase | Focus | Tools |
|---|---|---|
| [Phase 1](phase1-threat-assessment) | Threat assessment and executive summary | CIA Triad, risk analysis |
| [Phase 2](phase2-secure-remote-admin) | Secure remote administration | OpenSSH, UFW, PuTTY, Nmap |
| [Phase 3](phase3-data-integrity) | Data integrity verification | SHA-256, chmod |
| [Phase 4](phase4-network-monitoring) | Network monitoring and validation | Wireshark, auth logs |

## Final deliverable
A single PDF Incident Report with the executive summary and captioned screenshots for each phase (see final-report/).

## Lab environment
- Host: Windows with PuTTY, Nmap, and Wireshark
- Target: Linux VM running in VMware
